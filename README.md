# FDEcology
Codes used for data processing for the Flash Drought impact on Ecological Health.

Library Shared:

1- FLASH DROUGHT PROCESSING - Chitresh Anand

  1.1 - Flash Drought Workflow - Identify Flash drought events
  
2- SIF PROCESSING - Ajeeta Shrestha

  2.1- GOSIF and FD Phases - Identify SIF value according to the date and location of FD event
  
  2.2- GOSIF Anomaly - Calculate SIF Anomaly values
  
  2.3- GOSIF Anomaly Statistics - Calculate statistics based on Anomaly
  
  2.4- GOSIF Anomaly Plotting - Plot maps showing anomaly results


3- NDVI PROCESSING - Revathi V V
  
  3.1- NDVI Time Interpolation - Adjust NDVI data to match time into pentads
  
  3.2- NDVI and FD Phases  - Identify NDVI value according to the date and location of FD event
  
  3.3- NDVI Anomaly - Calculate NDVI Anomaly values
  
  3.4- NDVI Anomaly Statistics - Calculate statistics based on Anomaly
  
  3.5- NDVI Anomaly Plotting - Plot maps showing anomaly results
  
4- Land Cover and Ecoregion Processing - Layda Spor Leal
  
  4.1- Landcover Coordinates by Year - Identify the landcover for each coordinate and year
  
  4.2- Prevalent Landcover Map - Grid map, assign the most prevalent landcover for each cell
  
  4.3- Bar Chart by Landcover and FD phase - Plot bar charts showing the anomaly based on the landcover and FD phase
  
  4.4- Anomaly Heatmaps by NDVI - Plot NDVI average anomaly filtered by landcover and ecoregion
  
  4.5- Anomaly Heatmaps by SIF - Plot SIF average anomaly filtered by landcover and ecoregion
